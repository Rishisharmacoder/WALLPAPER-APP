# Wallpaper App

A mobile-first wallpaper app built with Expo and React Native for browsing, previewing, and setting wallpapers.

## Features

- Browse a collection of wallpaper images
- Preview wallpapers in-app
- Set wallpaper directly from the app
- Clean mobile UI with responsive layouts
- Cross-platform support via Expo

## Tech Stack

- React Native
- Expo
- TypeScript
- Expo Router

## Getting Started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the development server

   ```bash
   npx expo start
   ```

3. Open the app in:
   - Android emulator
   - iOS simulator
   - Expo Go
